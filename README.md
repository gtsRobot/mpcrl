# mpcrl

Standalone source snapshot of the `mpcrl` Python package from the MPC/LeWM residual reinforcement learning experiment workspace, uploaded on 2026-10-06.

The source is in `mpcrl/`. Download the repository with **Code → Download ZIP**, or clone it:

```bash
git clone https://github.com/gtsRobot/mpcrl.git
```

This repository contains the package source only. Experiment entry points, configurations, datasets, checkpoints, and tests are maintained separately in the full project. It is not a complete standalone experiment runner.
